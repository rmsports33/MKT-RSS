# mkt-flow-escrita — Escrita Acadêmica Controlada

**Domínio separado do pipeline de afiliados (MKT Flow).**
Decisão v3.10 (28/08/2026): a escrita acadêmica é um produto 100% distinto do marketing de afiliados
— misturá-los criava duplicação de código e confusão de responsabilidade.

## O que é

System prompts + processo controlado de escrita acadêmica:
- **MDA AUTO** — Assistente autônomo de escrita, pesquisa e revisão acadêmica
  (processo por etapas, arquitetura do argumento, auditoria, compressão não destrutiva, ABNT).
- **EAC** — Assistente de escrita acadêmica controlada (seções, auditoria transversal, gravidade).
- **Prompt-Mestre** — processo interno silencioso de 8 etapas + checklist final.
- **MCA AUTO** — conteúdo comercial/afiliados (transitório: mantido aqui até o marketing de
  afiliados consumi-lo via prompts dedicados no MKTFLOW).

## Como usar

Cole o prompt do arquivo desejado em um agente de IA apontado para esta pasta, ou use como
referência de processo. Não há código executável aqui — são **prompts e manuais de processo**.

## Versionamento

Segue o esquema do MCA/MDA AUTO (MAJOR.MINOR, ex.: 2.9). Não usa a versão do MKT Flow.
