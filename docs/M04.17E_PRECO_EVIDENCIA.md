## 1. O gargalo real

O gate de valor (M04.17D) exige `price_history` com:
- preço no formato que o gate lê (R$ X.XXX,XX)
- data de captura válida (DD/MM/AAAA)
- link do marketplace (fonte verificável)
- vínculo inequívoco com o produto

**Hoje o `price_history` é entrada externa/manual** — não existe coleta automatizada:
- O redator não tem produtor de `price_history` (só consumidor)
- Os coletores do redator BLOQUEIAM marketplaces explicitamente
- No MKT-RSS, `marketplaces.json` existe mas NÃO é usado por nenhum `.py`

## 2. Solução: coletor via APIs oficiais gratuitas

`mkt_flow_p0/price_collector.py` — coleta via APIs OFICIAIS gratuitas:
- **Amazon PA-API 5.0** — requer ACCESS_KEY/SECRET_KEY/ASSOCIATE_TAG
- **Mercado Livre API** — requer APP_ID/CLIENT_SECRET (Client Credentials)
- **Shopee Affiliate API** — requer PARTNER_ID/PARTNER_KEY

Credenciais lidas do ambiente (`.env` / GitHub Secrets) — **nenhuma dependência paga**.

### Evidência de preço coletada

Cada preço coletado produz evidência estruturada:
```python
{
  "ok": True,
  "marketplace": "amazon",
  "preco_br": "R$ 5.999,00",    # formato que o gate lê
  "data_captura": "17/09/2026",  # DD/MM/AAAA validada
  "url_oferta": "https://www.amazon.com.br/dp/B0XXX",
  "marketplace": "amazon"
}
```

### Persistência local (auditoria)

Cada preço coletado é gravado em SQLite local (`price_evidence.sqlite`):
- `produto`, `marketplace`, `preco_br`, `data_captura`, `url_oferta`
- `payload_bruto` (sem chaves secretas), `hash_evidencia` (dedup), `coletado_em`
- UNIQUE por `(produto, marketplace, hash_evidencia)` — deduplicação exata

### Fallback seguro (fail-closed)

Sem credenciais → **nenhuma requisição de rede** → erro explicativo:
```json
{"ok": false, "erros": ["nenhum marketplace configurado com credenciais válidas"]}
```

Sem credenciais = nenhuma requisição de rede = nenhuma violação de ToS.

## 3. Defeito descoberto (e corrigido) no dry-run real

O critério `preco_br_data` era **inalcançável** pela cadeia real:
- Contrato guardava `"5.999,00"` (sem `R$`)
- Regex do gate `_PRECO_BR` exige `R$` → `"5.999,00"` não casa
- Nenhum teste anterior pegou porque o comparativo do M04.17B passava pelo cruzamento

**Correção no produtor** (`_preco_do_historico`):
```python
melhor = ("R$ " + preco, data, fonte)  # guarda com R$
```
Gate **não foi afrouxado** — mudar a regex aceitaria número solto = falso positivo.

Prova: `tools/2026-10-21_provar_preco_br_data.py` (antes `False` → depois `True`).
Contraprova: preço sem marketplace **continua** sem o critério.
