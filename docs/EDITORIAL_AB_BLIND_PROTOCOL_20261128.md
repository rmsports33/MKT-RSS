# Protocolo A/B cego da qualidade v1.1 — 28/11/2026

Objetivo: verificar se o contrato v1.1 melhora a avaliação editorial em relação ao processo anterior.
A nota 0–100 permanece **diagnóstica** e nunca autoriza publicação.

## Desenho

Três gêneros, com textos comparáveis:

1. notícia factual;
2. análise econômica;
3. artigo explicativo.

Para cada gênero:

1. selecionar textos comparáveis com as mesmas fontes e o mesmo briefing;
2. avaliar com o processo anterior e com o contrato v1.1;
3. ocultar dos avaliadores qual método produziu cada avaliação;
4. comparar com avaliador humano independente;
5. medir falsos positivos, falsos negativos, utilidade dos apontamentos e divergências;
6. registrar os resultados sem converter nota em aprovação.

## Campos de registro

| Campo | Conteúdo |
|---|---|
| Gênero | notícia / análise / explicativo |
| Identificador do texto | sem identificação do produtor |
| Avaliação A | processo anterior |
| Avaliação B | contrato v1.1 |
| Avaliador humano | identificação e data |
| Falsos positivos / negativos | contagem com exemplos |
| Utilidade dos apontamentos | diagnóstico do avaliador humano |
| Divergências | onde A e B discordaram |
| Decisão | homologar v1.1 / ajustar / rejeitar |

## Regras

- Sem identificação de método para o avaliador humano.
- Sem troca de modelo, parâmetros ou fontes entre A e B.
- Sem conclusão baseada apenas em testes automatizados.
- Sem publicação automática decorrente do resultado.
