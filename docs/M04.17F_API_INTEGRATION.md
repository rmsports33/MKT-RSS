# M04.17F — Integração dos clientes de API de marketplaces

Data: 22/10/2026 · Branch: `feat/m0417f-api-integracao` · PR #12

## 1. Resumo

Implementação dos clientes para as APIs oficiais dos três marketplaces principais,
com autenticação, rate limiting, retry e validação de respostas.

## 2. Componentes entregues

### 2.1 `mkt_flow_p0/price_api_clients.py`

| Cliente | API | Autenticação | Rate Limit |
|---|---|---|---|
| `AmazonPAAPIClient` | Product Advertising API 5.0 (GetItems) | AWS Signature V4 | 1 req/s (configurável) |
| `MercadoLivreClient` | Items API | OAuth2 Client Credentials | 10 req/s |
| `ShopeeClient` | Affiliate API (Get Item Base Info) | HMAC-SHA256 | 5 req/s |

**Infraestrutura comum:**
- `TokenBucket` — rate limiting com modo não-bloqueante (`blocking=False`)
- `Retry` (urllib3) — backoff exponencial para 429/5xx
- Validação de resposta antes de retornar
- Fallback fail-closed: sem credenciais → erro sem requisição
- Zero dependências pagas; `requests` + stdlib apenas

## 3. Defeito crítico corrigido

O critério `preco_br_data` era **inalcançável** pela cadeia real:
- Contrato guardava `"5.999,00"` (sem `R$`)
- Regex do gate `_PRECO_BR` **exige** `R$`
- Correção no produtor (`_preco_do_historico` agora guarda `"R$ 5.999,00"`)
- **Gate NÃO foi afrouxado** — mudar a regex aceitaria número solto = falso positivo
- Prova: `tools/2026-10-21_provar_preco_br_data.py` (antes `False` → depois `True`)

## 4. Configuração necessária

Configure as variáveis no `.env` ou GitHub Secrets:

```bash
# Amazon PA-API 5.0
AMAZON_PA_API_ACCESS_KEY=...
AMAZON_PA_API_SECRET_KEY=...
AMAZON_PA_API_ASSOCIATE_TAG=...
AMAZON_PA_API_REGION=BR

# Mercado Livre
MERCADOLIVRE_APP_ID=...
MERCADOLIVRE_CLIENT_SECRET=...

# Shopee
SHOPEE_PARTNER_ID=...
SHOPEE_PARTNER_KEY=...
```

Sem credenciais → **nenhuma requisição** → erro explicativo → não viola ToS.
