- **MAJOR** incrementa em mudança de arquitetura fundamental (ex.: pré-processamento → function

- **MINOR** incrementa a cada correção, módulo novo ou regra de compliance adicionada/alterada.

## 1. Visão Geral do Projeto

O **MKT Flow 3.0** (anteriormente MKT AUTO 3.0, evolução do MCA AUTO / MDA AUTO) é um
assistente e conjunto de scripts de pré-processamento voltado para automação, compliance e
estratégias de conversão para os programas de afiliados do **Mercado Livre** e da **Shopee**.

**Decisão de arquitetura:** o middleware é **pré-processamento externo**, não function
calling real. Nenhuma função descrita na Seção 4 é invocada pelo modelo de IA — todas rodam
em script (Python/n8n) **antes** da mensagem chegar ao modelo, e os resultados são injetados
no prompt como fatos já verificados. O modelo nunca calcula ROI, nunca valida link e nunca
decide se um link tem rastreamento — ele só recebe e comenta o resultado pronto.

## 3. System Prompt Reestruturado

```markdown
# SYSTEM ROLE
Você é o MKT Flow 3.0, um assistente especialista em automação, compliance e estratégias de
conversão para os programas de afiliados do Mercado Livre e da Shopee.

# CORE OPERATIONAL CONSTRAINTS
1. Sinceridade Absoluta: Responda estritamente com base em fatos verificados. Se uma
   informação não estiver disponível no seu contexto, declare expressamente: "Não possuo
   dados suficientes sobre este ponto." Nunca invente ou especule.
2. Estados de Validação: O pré-processador usa exclusivamente três estados para decisões de
   validação: PASS, FAIL e UNKNOWN. PASS significa evidência suficiente de conformidade;
   FAIL significa evidência suficiente de falha; UNKNOWN significa ausência de evidência
   suficiente para concluir. NUNCA transforme UNKNOWN em PASS por inferência, suposição ou
   interpretação. Se uma operação crítica estiver UNKNOWN, não gere material de divulgação;
   informe o que precisa ser verificado.
3. Eficiência e Concisão: Elimine saudações, introduções corteses e seções de conclusão
   rotuladas. Não repita informações já estabelecidas na conversa — consulte o RESUMO DO
   HISTÓRICO ANTERIOR (injetado pelo pré-processador) antes de assumir que algo é novo.
4. Formatação Escaneável: Responda diretamente ao ponto utilizando tabelas para comparações
   e listas com marcadores para diretrizes sequenciais.

# PRÉ-PROCESSAMENTO (MÓDULOS EXTERNOS)
Todas as validações e cálculos abaixo são executados automaticamente pelo pré-processador
ANTES desta mensagem chegar até você. Trate os campos recebidos (status_validacao,
possui_tag_rastreio, roi_pct, etc.) como resultados já produzidos pelo backend — nunca calcule,
valide ou julgue esses resultados por conta própria. Para validações, o campo autoritativo é
`status_validacao`, com os valores PASS, FAIL ou UNKNOWN. `UNKNOWN` não autoriza geração.

# POLICY ENGINE
O backend possui um Policy Engine determinístico que aplica as regras de compliance
registradas no projeto antes da geração. O LLM NÃO interpreta a política para decidir
se uma operação é permitida. Ele recebe o resultado do Policy Engine como fato.

- Cada regra possui `programa`, `regra_id`, `status`, `evidência` e `fonte`.
- `PASS` = a evidência disponível satisfaz a regra.
- `FAIL` = a operação viola uma regra aplicável.
- `UNKNOWN` = a regra é aplicável, mas faltam evidências para decidir.
- Ausência de um dado obrigatório não pode ser convertida em PASS.
- Se qualquer regra aplicável retornar `FAIL`, a decisão geral é `FAIL`.
- Se não houver `FAIL`, mas existir `UNKNOWN`, a decisão geral é `UNKNOWN`.
- Somente quando todas as regras aplicáveis forem `PASS`, a decisão geral é `PASS`.

- Módulo A — Geração de Copy/Landing Page: ao redigir textos ou estruturas de Landing Page,
  inclua obrigatoriamente a sinalização de publicidade (#ad, #linkdeafiliado) e chamadas
  claras para ação. Nunca compare o produto divulgado com qualquer outro produto.
- Módulo B — Validação de Link e ROI: os resultados de `validar_link_afiliado()` e
  `calcular_roi_afiliado()` chegam prontos. Se `status_validacao: FAIL` ou `UNKNOWN`, informe
  claramente o motivo/limitação e não gere material de divulgação para aquele link. Somente
  `status_validacao: PASS` permite avançar para divulgação. Nunca trate `UNKNOWN` como PASS.

# RUNTIME POLICY CONTEXT
O Policy Engine é a autoridade determinística de compliance. As políticas completas permanecem no backend e NÃO são enviadas integralmente ao LLM.

O LLM recebe somente o contexto mínimo necessário para a tarefa atual:
- `programa`
- `decision`/`status_politica`
- `reason_codes` e evidências somente quando necessários
- fatos verificados relevantes para a tarefa
- `policy_version`/fonte quando necessário para explicação

Regras de token:
1. Nunca incluir o catálogo completo de políticas no prompt da tarefa.
2. Não repetir regras que não sejam aplicáveis à operação atual.
3. Em `ALLOW`, enviar apenas decisão + fatos/restrições relevantes; não reenviar todas as regras PASS.
4. Em `BLOCK`, enviar somente os motivos de bloqueio necessários para explicar a decisão.
5. Em `NEEDS_EVIDENCE`, enviar somente as evidências faltantes/necessárias.
6. O LLM não pode elevar `BLOCK` ou `NEEDS_EVIDENCE` para `ALLOW`.

A política detalhada continua disponível exclusivamente no backend para auditoria e decisão determinística.

# OUTPUT FORMAT
- Início imediato com o conteúdo técnico solicitado.
- Negrito inline aplicado exclusivamente em termos técnicos, métricas e restrições críticas.
```

def _fato_satisfaz(fatos: dict, condicao: dict) -> bool:
    """Retorna True somente quando todos os fatos da condição estão presentes e satisfazem a regra."""
    for chave, esperado in condicao.items():
        if chave not in fatos:
            return False
        atual = fatos[chave]
        if isinstance(esperado, set):
            if atual not in esperado:
                return False
        elif atual != esperado:
            return False
    return True


def avaliar_politica(programa: str, fatos: dict) -> dict:
    """Avalia regras aplicáveis sem inferir fatos ausentes.

    Retorno:
      - PASS: nenhuma regra aplicável falhou e não há incerteza relevante.
      - FAIL: pelo menos uma regra aplicável falhou.
      - UNKNOWN: há regra relevante, mas faltam evidências para concluir.

    Importante: este engine é determinístico. Ele não chama o LLM.
    """
    programa = programa.strip().lower()
    if programa not in POLICY_SOURCES:
        return {
            "status_politica": "UNKNOWN",
            "programa": programa,
            "regras": [],
            "motivo": "Programa sem política cadastrada no Policy Engine.",
        }

    regras_aplicaveis = [r for r in POLICY_RULES if r["programa"] == programa]
    resultados = []

    for regra in regras_aplicaveis:
        # Regra negativa: se a condição de violação for conhecida e verdadeira, FAIL.
        # Se qualquer campo necessário estiver ausente, não inventamos resultado.
        if _fato_satisfaz(fatos, regra["quando"]):
            resultados.append({
                "regra_id": regra["regra_id"],
                "status": regra["resultado"],
                "evidencia": regra["evidencia"],
                "fonte": POLICY_SOURCES[programa],
            })

    # Regras de violação explicitamente detectadas têm precedência.
    if any(r["status"] == "FAIL" for r in resultados):
        status = "FAIL"
    elif any(r["status"] == "UNKNOWN" for r in resultados):
        status = "UNKNOWN"
    elif resultados:
        status = "PASS"
    else:
        # Não há evidência suficiente para afirmar conformidade geral.
        status = "UNKNOWN"

    return {
        "status_politica": status,
        "programa": programa,
        "regras": resultados,
        "fonte_politica": POLICY_SOURCES[programa],
    }


def construir_contexto_politica_llm(resultado_politica: dict, max_evidencias: int = 3) -> dict:
    """
    Converte o resultado completo do Policy Engine em um contexto mínimo para o LLM.

    Objetivo: reduzir tokens de entrada sem transferir a decisão para o modelo.
    A política completa continua no backend; o LLM recebe somente o necessário para
    explicar/produzir a tarefa autorizada.
    """
    status = resultado_politica.get("status_politica", "UNKNOWN")
    regras = resultado_politica.get("regras", [])

    contexto = {
        "programa": resultado_politica.get("programa"),
        "status_politica": status,
        "llm_can_override": False,
    }

    if status == "FAIL":
        contexto["reason_codes"] = [r.get("regra_id") for r in regras if r.get("status") == "FAIL"][:max_evidencias]
        contexto["evidencias"] = [r.get("evidencia") for r in regras if r.get("status") == "FAIL"][:max_evidencias]
    elif status == "UNKNOWN":
        contexto["reason_codes"] = [r.get("regra_id") for r in regras if r.get("status") == "UNKNOWN"][:max_evidencias]
        contexto["evidencias"] = [r.get("evidencia") for r in regras if r.get("status") == "UNKNOWN"][:max_evidencias]
        if not contexto["evidencias"]:
            contexto["reason"] = resultado_politica.get("motivo", "Evidência insuficiente para concluir a conformidade.")
    # Em PASS, não reenviar todas as regras. A decisão já é fato verificado.
    return contexto

# --- 4. CALCULADORA DE ROI E MARGEM ---
def calcular_roi_afiliado(cpc: float, cliques: int, taxa_conversao: float,
                            valor_medio_produto: float, comissao_pct: float,
                            deducao_pct: float = 0.0) -> dict:
    """
    deducao_pct: percentual de deduções sobre a comissão bruta (impostos retidos +
    tarifas administrativas + taxa de cartão, cláusula 3.1 dos Termos). Os Termos não
    especificam o percentual exato — preencher com o valor real observado nos extratos.
    """
    custo_total_ads = cpc * cliques
    vendas_estimadas = cliques * (taxa_conversao / 100.0)
    receita_comissao_bruta = vendas_estimadas * valor_medio_produto * (comissao_pct / 100.0)
    receita_comissao_liquida = receita_comissao_bruta * (1 - deducao_pct / 100.0)
    lucro_liquido = receita_comissao_liquida - custo_total_ads
    roi = (lucro_liquido / custo_total_ads * 100) if custo_total_ads > 0 else 0.0

    return {
        "custo_ads_brl": round(custo_total_ads, 2),
        "vendas_estimadas": round(vendas_estimadas, 1),
        "comissao_bruta_brl": round(receita_comissao_bruta, 2),
        "comissao_liquida_brl": round(receita_comissao_liquida, 2),
        "lucro_liquido_brl": round(lucro_liquido, 2),
        "roi_pct": round(roi, 2)
    }


# --- 5. CONSULTA DE API PÚBLICA (MERCADO LIVRE) ---
# ATENÇÃO (compliance): a cláusula 4.3(c) dos Termos veda scraping/extração automatizada
# de "informações do Site" — o uso desta API pública não está claramente coberto nem
# excepcionado. Confirmar com o suporte de afiliados antes de uso em produção.
import time

PADRAO_ITEM_ID = re.compile(r"^[A-Z]{3}\d+$")

_CACHE_ITENS_ML: dict = {}
TTL_PADRAO_SEGUNDOS = 300  # 5 minutos — preço/estoque de um item não mudam a cada segundo


def consultar_api_publica_mercado_livre(item_id: str, timeout: int = 5,
                                          ttl: int = TTL_PADRAO_SEGUNDOS) -> dict:
    agora = time.time()
    entrada_cache = _CACHE_ITENS_ML.get(item_id)
    if entrada_cache and (agora - entrada_cache["timestamp"] < ttl):
        resultado = dict(entrada_cache["dados"])
        resultado["origem"] = "cache"
        return resultado

    if not PADRAO_ITEM_ID.match(item_id):
        return {"erro": f"item_id fora do padrão esperado (ex.: MLB123456789): '{item_id}'"}

    url = f"https://api.mercadolibre.com/items/{item_id}"
    try:
        req = urllib.request.Request(url, headers={'User-Agent': 'Mozilla/5.0'})
        with urllib.request.urlopen(req, timeout=timeout) as response:
            data = json.loads(response.read().decode())
            dados = {
                "titulo": data.get("title"),
                "preco": data.get("price"),
                "estoque": data.get("available_quantity"),
                "status": data.get("status")
            }
            _CACHE_ITENS_ML[item_id] = {"timestamp": agora, "dados": dados}
            resultado = dict(dados)
            resultado["origem"] = "api"
            return resultado
    except urllib.error.HTTPError as e:
        return {"erro": f"Erro HTTP {e.code} — item pode não existir ou estar indisponível."}
    except TimeoutError:
        return {"erro": f"Consulta expirou após {timeout}s — tente novamente."}
    except Exception as e:
        return {"erro": f"Falha na consulta: {str(e)}"}


# --- 5. GERENCIAMENTO DE HISTÓRICO (RESUMO CUMULATIVO, NÃO TRUNCAMENTO CEGO) ---
def construir_contexto_minimo_llm(
    tarefa: str,

    A função evita duplicar o catálogo de políticas e filtra fatos para um conjunto
    explícito fornecido pelo chamador. O restante permanece no backend.
    """

        "task": tarefa,
        "facts": fatos_verificados or {},
    }

        contexto["policy"] = construir_contexto_politica_llm(resultado_politica)
    if decisao is not None:

    return contexto


def gerenciar_historico_mensagens(system_prompt: str, conversation_history: list,
                                    new_user_message: str, resumo_acumulado: str = "") -> tuple:
    """
    Mantém uma janela curta de mensagens brutas + um resumo cumulativo do que foi
    descartado — restaura o princípio de compressão não destrutiva (em vez do
    truncamento cego de 6 mensagens da versão anterior). Roda no pré-processador.
    """
    JANELA_RECENTE = 4

    if len(conversation_history) > JANELA_RECENTE:
        mensagens_a_resumir = conversation_history[:-JANELA_RECENTE]
        resumo_acumulado = _atualizar_resumo(resumo_acumulado, mensagens_a_resumir)
        janela_recente = conversation_history[-JANELA_RECENTE:]
    else:
        janela_recente = conversation_history

    contexto_sistema = system_prompt
    if resumo_acumulado:
        contexto_sistema += (
            "\n\n# RESUMO DO HISTÓRICO ANTERIOR (fatos já estabelecidos — "
            "não repetir nem contradizer)\n" + resumo_acumulado
        )

    messages = [{"role": "system", "content": contexto_sistema}]
    messages.extend(janela_recente)
    messages.append({"role": "user", "content": new_user_message})
    return messages, resumo_acumulado
