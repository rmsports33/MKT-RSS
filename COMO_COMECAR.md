# 🚀 Como começar a trabalhar neste projeto (para iniciantes)

Não é preciso saber programar. Siga apenas estes passos:

## 1. Antes de começar qualquer coisa

Clique duas vezes no arquivo **`iniciar.bat`** (Windows) ou **`iniciar.sh`** (Linux/Mac).

Ou rode no terminal:
```bash
python tools/iniciar.py
```

## 2. O que ele faz

Ele sozinho:
- Verifica se tudo está registrado corretamente
- Corrige automaticamente se algo faltar
- Diz se pode começar ou o que ainda falta

## 3. Quando terminar o seu trabalho

Rode o mesmo arquivo novamente (`iniciar.bat` ou `iniciar.sh`).
Ele vai salvar tudo o que você fez no registro do projeto.

## 4. Se algo der errado

O próprio arquivo vai dizer em palavras simples o que está faltando.
Não precisa adivinhar: basta seguir o que ele informa.

---

**Regra de ouro:** Sempre comece e termine rodando `tools/iniciar.py`.
