# ⚠️  LEMBRETE: Leia isto ANTES de começar

Este arquivo é um lembrete para qualquer pessoa ou IA que for trabalhar neste projeto.

## O que fazer SEMPRE antes de começar

Rode este comando:

```bash
python tools/iniciar.py
```

Ou dê duplo-clique em:
- `iniciar.bat` (Windows)
- `iniciar.sh` (Linux/Mac)

## O que ele faz sozinho

1. Verifica se o projeto está pronto para receber trabalho
2. Corrigi automaticamente se algo estiver faltando
3. Diz em palavras simples se pode começar ou o que ainda falta

## Quando rodar novamente

- **Antes de começar** qualquer tarefa
- **Quando terminar** o trabalho (para salvar tudo)
- **Sempre que mudar de plataforma** (OpenCode, ChatGPT, DeepSeek, etc.)

## Se não fizer isso

O projeto pode perder o que foi feito entre sessões. As regras estão no `docs/REGISTRO_UNICO_20261118.md` e no `AGENTS.md`.

---

**Não pule este passo.** É assim que o projeto fica organizado e não quebra.
